# Tech Company Customer Repair Tracker

A lightweight, automated repair ticket tracking web portal designed for hardware repair shops, MSPs, and IT service providers.

## Features
- **Live 5-Stage Stepper:** Visual tracking from check-in to diagnostics, soldering, QA, and pickup.
- **Bench Simulator:** Includes a top-bar control to test how the UI updates across repair stages in real time.
- **Diagnostic Checklist:** Interactive 32-point checklist showing hardware benchmarks.
- **Live Quote Add-ons:** Customer can approve or decline additional parts with automatic balance recalculation.
- **Curbside Pickup Notification:** Real-time collection alerts for customers at the door.
- **Two-Way Workshop Desk Chat:** Direct communication between customer and lead technician.

## How to Run Locally
1. Clone this repository:
   ```bash
   git clone [https://github.com/](https://github.com/)<your-username>/repair-tracker.git
   cd repair-tracker
   ```
2. Open `index.html` in any browser:
   - On Windows: double-click `index.html`
   - On macOS: `open index.html`
   - On Linux: `xdg-open index.html`

## Deploy to GitHub Pages
1. Go to your repository on GitHub.
2. Click **Settings** > **Pages** (in the left sidebar).
3. Under **Branch**, select `main` (or `master`) and folder `/ (root)`.
4. Click **Save**. Your site will be live at `https://<your-username>.github.io/repair-tracker/`.
